## 一、一句话概括

**这不是模型选型视频，而是一个"换掉文本编码器"的部署教程**：教你在最新版 ComfyUI 里跑 H3，并把官方的 Qwen3-VL-32B 文本编码器
换成社区的无审查（abliterated / heretic）版本，从而绕过官方模型对提示词的拒绝行为。视频 7:08 之后演示的正是"官方会拒、换成这个就能生成"，
并对画面下部做了打码处理。

## 二、视频的完整操作流程（口播顺序）

| 步骤 | 内容 |
|---|---|
| 1 | 去配文页下载"越狱模型"：一个 **无审查的 H3 文本编码器**，约 14.6–15.7 GB，UP 说 16 GB 显存的卡就能跑 |
| 2 | 下载安装最新版 ComfyUI 桌面版（约 150 MB）；**中国大陆必须开镜像加速**，否则后续主模型下不下来 |
| 3 | 打开 ComfyUI → 左侧「模板」→ 进入模型中心 → 选 Video → 找到 MiniMax H3 的图生视频 / 文生视频模板 → 提示缺模型时点「全部下载」 |
| 4 | 把第 1 步下载的编码器放进 `ComfyUI/models/text_encoders`（默认装在 C 盘时是 `C:\Users\<用户名>\AppData\Local\Comfy-Desktop\ComfyUI-Shared\models\text_encoders`） |
| 5 | 在工作流里找到 `CLIPLoader` 节点 → 按 **S** 刷新 → 把编码器从官方版换成那个 heretic 版本 |
| 6 | 输入提示词 → 跑图生视频（10 秒）→ 再跑文生视频（30 秒，"边关战争"剧情） |
| 7 | 演示"越过限制"：输入 UP 称为"无法描述"的提示词，生成后只放出画面上半部分 |
| 8 | 结尾：这类生成的音画"无版权可商用"，也支持视频生视频 |

## 三、里面确实有用的技术信息（3 条）

1. **替换点就是文本编码器，扩散模型完全不动。** 这是这条"越狱"路线的全部技术内容 ——
   它只改变模型对提示词的语义理解与拒绝行为，**不改变画质、运动能力和时长上限**。
   所以你在视频里看到的画面质量，跟官方编码器跑出来的是一个量级。
2. **尺寸对齐所以能直接换**：该 heretic 编码器是 NVFP4、约 14.6–15.7 GB，与 Comfy-Org 官方 NVFP4 AWQ 编码器同尺寸，
   工作流其余部分一行不用改 —— 这也解释了为什么它能"开箱替换"。
3. **30 秒是分段拼的**，不是一次生成：H3 单次上限是 4–15 秒，视频里的"30 秒剧情"是分镜拼接 + 后期处理的结果
   （UP 自己也说要"加入人物对话、脸部特写、背景音乐刻画"）。

## 四、要打问号 / 视频漏掉的（5 条）

1. **"不牺牲精度还适配小显存"站不住**：abliteration 是让模型在拒绝类输出上"失能"，与量化精度是两码事；
   同尺寸只说明显存占用一样，不代表质量一样。**12–16 GB 卡的真实瓶颈依然是内存（32–64 GB）和 NVMe，视频一个字没提。**
2. **本地仍然只有 768p**（短边 768），2K 未开源 —— 老问题，与本视频无关，但它演示"电影级"时容易让人误解。
3. **没提 CUDA 13**：cu128 的 PyTorch 会静默关掉 int8-convrot 快速路径，慢约 3 倍。
4. **没提 `--disable-pinned-memory`**：32 GB 内存的机器不加这个标志，加载阶段会被系统杀掉。
5. **没提许可**：MiniMax H3 社区许可排除美/欧/英/韩，且条款覆盖输出物与衍生模型；"无版权可自由商用"这个说法只针对生成内容本身的版权主张，
   **不等于拿到 H3 的开源许可授权**，两件事别混。

## 五、风险与边界（这部分请认真看）

- 视频后半段演示的玩法，本质是用无审查编码器生成**官方模型会拒绝的内容**。如果落到国内法律语境，
  制作或传播淫秽色情内容是有明确法律风险的，**这部分我不会提供任何配置、提示词或绕审思路**，请自行评估。
- 第三方"越狱"权重的**来源与完整性无法验证**（同类教程常见网盘、聚合站分发），来源不明的模型文件本身也是风险。
- 顺带说一句：**这条路线对你的选型结论没有任何影响**。你关心的是 4070 Super / 4070 Ti Super 下哪个量化档能跑得动 ——
  换不换文本编码器，显存、内存、硬盘、768p 上限、CUDA 13 这些约束全都一样。
  如果你要的是"创作自由度"，值得先确认自己真正缺的是内容自由度，还是画质与分辨率 —— 后者本地给不了，只有 API 的 2K 能给。
